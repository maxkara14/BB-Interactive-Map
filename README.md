# BB Interactive Map

Терминал интерактивной карты и пространственной памяти для SillyTavern. Сканирует текущую сцену и превращает её в 3x3 карту окружения.

## Возможности

- **Сканирование сцены** - анализирует последние сообщения и строит карту локации.
- **3x3 сетка** - показывает центр, стороны света и угловые зоны.
- **Два масштаба** - режим `Комната` для ближайшего пространства и режим `Здание` для окружения шире текущей комнаты.
- **Телеметрия зон** - отображает персонажей, настроение, отношение, мысли, объекты и краткое описание зоны.
- **Уровни угрозы** - зоны подсвечиваются как safe, tension или danger.
- **Память локации** - карту можно сохранить в `chat_metadata`, чтобы ИИ учитывал пространственную сводку.

## Настройки и интеграция

- По умолчанию сохранённая карта автоматически внедряется в контекст.
- Можно включить ручной режим и вставлять карту через макрос `{{bb_map}}`.
- Поддерживается OpenAI-compatible Custom API: свой URL, API-ключ и модель для генерации карты.
- Если Custom API недоступен, используется основная генерация SillyTavern.

## Установка

1. Откройте SillyTavern.
2. Перейдите в `Расширения -> Установить расширение`.
3. Вставьте ссылку на репозиторий:
   `https://github.com/maxkara14/BB-Interactive-Map`
4. Перезагрузите страницу.
5. Кнопка `Интерактивная карта` появится в меню расширений.
